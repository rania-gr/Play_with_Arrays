# Play_with_Arrays
It's a simple code in C language that shows how to manipulate arrays. it's basically a homework in Uni (USTHB) 
How it works :
Part 1:
_the programs asks the user how many numbers they wanna enter.
they enter the numbers one by one.
then it instantly gives the minimum and maximum and the average of the negative numbers and the product of the positive numbers!
Part 2 :
_the user chooses a number among them, so the program gives how many times the number given occurred!
Part 3 :
_the user chooses a random number in their mind and chooses the position (the program already wrote the list of numbers in order),the program inserts the number given in the the position chosen 
Part 4 :
the program removes all zeros
Part 5:
the program moves all the negative numbers to the left side!
*

_arrays T[i]
_loops (for)
_if/else statement 
_swap method 
_logical and arithmetic operations
